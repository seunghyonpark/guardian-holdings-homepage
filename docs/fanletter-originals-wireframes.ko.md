# FanLetter Originals MVP 와이어프레임

이 문서는 디자인 시안이 아니라 MVP 화면 구조를 맞추기 위한 기능 와이어프레임이다. 실제 UI에서는 FanLetter의 기존 모바일 숏폼 경험을 우선한다.

## 1. 팬 화면 IA

```text
Home / Discovery
  -> Character Channel
      -> Vlog Player
      -> Episode Reader
      -> Fan Letter Composer
      -> Growth Log
      -> Canon Board
      -> Paid Unlock
```

팬 경험의 핵심 경로:

```text
브이로그 시청
  -> 팬레터 또는 다음 장면 요청
  -> 성장 로그 업데이트
  -> 작가가 요청 채택
  -> 공식 에피소드/후속 브이로그 공개
  -> 팬 재방문/결제
```

## 2. 작가 화면 IA

```text
Writer Studio
  -> Character Bible
  -> Vlog Planner
  -> Fan Inbox
  -> Canon Board Manager
  -> Episode Editor
  -> Analytics / Revenue
```

## 2.1 광고주 화면 IA

```text
Advertiser Studio
  -> New Product Campaign
  -> Campaign Draft
  -> Character Match
  -> Approval Status
  -> Campaign Report
```

광고주 경험의 핵심 경로:

```text
상품 URL 입력
  -> 상품 카드 확인
  -> 캐릭터 추천 선택
  -> 캠페인 공유링크 발급
  -> 클릭/전환 리포트 확인
```

작가 경험의 핵심 경로:

```text
캐릭터 생성
  -> 오늘의 브이로그 발행
  -> 팬 반응 확인
  -> 채택할 요청 선택
  -> 공식 에피소드 작성
  -> 다음 해금 조건 설정
```

## 3. 화면 1: Character Channel

목적:

- 캐릭터의 홈.
- 첫 화면에서 "이 캐릭터는 지금 살아 있고 성장 중"이라는 신호를 줘야 한다.

```text
┌─────────────────────────────────────┐
│ [Latest 9:16 Vlog Preview]           │
│                                     │
│  윤서                               │
│  오늘은 팬레터를 세 번 다시 읽었다 │
│  Writer: min                        │
│  Season 1 · Day 07                  │
│                                     │
│  친밀도 Lv.3  인지도 Lv.2           │
│  서사력 Lv.2  수익력 Lv.1           │
│                                     │
│ [팬레터] [다음 장면 요청] [후속 보기] │
├─────────────────────────────────────┤
│ Vlogs | Episodes | Growth | Canon   │
├─────────────────────────────────────┤
│ Latest Vlogs                         │
│ [thumb] 비 오는 퇴근길              │
│ [thumb] 팬레터를 읽은 밤            │
│ [thumb] 혼자 남은 연습실            │
└─────────────────────────────────────┘
```

필수 상태:

- 신규 캐릭터: 콘텐츠가 적을 때 첫 팬레터 CTA를 강하게 노출
- 성장 중 캐릭터: 다음 해금 조건 노출
- 유료 콘텐츠 보유 캐릭터: 공개 영상 아래 감정적 결제 포인트 노출
- 휴재/비활성 캐릭터: 최근 업데이트와 다음 예정일 노출

## 4. 화면 2: Vlog Player

목적:

- 팬이 캐릭터와 가장 직접적으로 만나는 화면.
- 영상 시청 후 즉시 행동이 나와야 한다.

```text
┌──────────────────────────────┐
│                              │
│        9:16 VLOG VIDEO        │
│                              │
│                              │
│                              │
├──────────────────────────────┤
│ 윤서 · Day 07                │
│ 팬레터를 읽은 밤             │
│                              │
│ "오늘은 잠이 잘 안 올 것 같아" │
│                              │
│ ♡ 1.2k   저장   공유          │
│                              │
│ [팬레터 보내기]               │
│ [다음 장면 요청]              │
│ [관련 에피소드 읽기]          │
└──────────────────────────────┘
```

주요 이벤트:

- `vlog_view_started`
- `vlog_view_completed`
- `fan_letter_opened`
- `next_scene_request_opened`
- `episode_clicked`
- `paid_unlock_clicked`

전환 규칙:

- 70% 이상 시청하면 팬레터 CTA 강조
- 관련 에피소드가 있으면 영상 종료 후 자동 노출
- 팬 요청 기반 영상이면 "팬 요청에서 시작된 장면" 표시


## 6. 화면 4: Growth Log

목적:

- 팬 행동이 캐릭터에 영향을 줬다는 증거를 제공한다.

```text
┌────────────────────────────────────┐
│ 윤서의 성장                         │
│                                    │
│ 친밀도 Lv.3  ███████░░░ 70%         │
│ 다음 해금: 비공개 답장 브이로그     │
│                                    │
│ 인지도 Lv.2  ████░░░░░░ 40%         │
│ 다음 해금: 추천 피드 부스트         │
│                                    │
│ 최근 변화                           │
│ + 팬레터 42개로 친밀도 Lv.3 달성    │
│ + "비 오는 날 산책" 요청 검토 중    │
│ + Episode 03 공개로 서사력 +20      │
└────────────────────────────────────┘
```

팬에게 보여줄 문장:

- "다음 18개의 팬레터가 도착하면 답장 브이로그가 열립니다."
- "이번 주 가장 많이 요청된 장면은 '퇴근길 통화'입니다."
- "당신의 요청이 작가 검토 목록에 올라갔습니다."

## 7. 화면 5: Canon Board

목적:

- 팬 요청이 공식화되는 과정을 보여준다.

```text
┌────────────────────────────────────┐
│ Canon Board                         │
│                                    │
│ [공식 캐논]                         │
│ "윤서가 팬레터를 보관한다"          │
│ 반영: Episode 02, Vlog Day 06       │
│ 작가: 이건 시즌 1 감정선에 중요함  │
│                                    │
│ [검토 중]                           │
│ "비 오는 날 직접 답장해 줬으면"    │
│ 팬 요청 28개                        │
│                                    │
│ [소프트 캐논]                       │
│ "아이스 아메리카노를 좋아함"        │
│ 반영: Vlog Day 04                   │
└────────────────────────────────────┘
```

상태별 처리:

- 제출됨: 팬이 방금 요청한 상태
- 검토 중: 작가 대시보드에 올라간 상태
- 소프트 캐논: 브이로그에는 반영됐지만 장기 설정은 아님
- 공식 캐논: 공식 에피소드/시즌 설정으로 반영
- 반려됨: 금지 설정, 캐릭터 붕괴, 안전 문제 등

## 8. 화면 6: Episode Reader

목적:

- 브이로그와 팬 반응이 공식 서사로 정리되는 곳.

```text
┌────────────────────────────────────┐
│ Episode 03                          │
│ 팬레터를 읽은 밤                    │
│ 윤서 · Season 1 · Day 07            │
│                                    │
│ 관련 브이로그: Day 07 보기          │
│ 팬 요청에서 시작된 에피소드         │
├────────────────────────────────────┤
│ 그날 밤, 윤서는 불을 끄지 못했다... │
│                                    │
│ [본문 800~2,000자]                  │
│                                    │
├────────────────────────────────────┤
│ [후속 브이로그 보기]                │
│ [다음 장면 요청]                    │
│ [팬레터 보내기]                     │
└────────────────────────────────────┘
```

주의:

- 회차 목록 중심의 전통 웹소설 UI로 가지 않는다.
- 읽은 뒤 반드시 브이로그나 팬 행동으로 돌아가야 한다.

## 10. 화면 8: Character Bible

목적:

- AI 캐릭터의 일관성을 만드는 기준 문서.

입력 필드:

```text
기본 정보
- 이름
- 장르
- 나이대
- 직업/역할
- 현재 목표

말투와 성격
- 1인칭 호칭
- 팬을 부르는 방식
- 자주 쓰는 표현
- 절대 하지 않는 말

세계관
- 배경
- 현재 시즌의 갈등
- 중요한 관계
- 숨겨야 할 스포일러

시각 설정
- 외형 키워드
- 의상 범위
- 장소 범위
- 금지 연출

운영 정책
- 팬 요청 허용 범위
- NSFW 여부
- 공개 가능 수위
- 작가 승인 필수 조건
```

## 14. 첫 개발 스프린트 범위

### Sprint 1

- 캐릭터 채널
- 브이로그 플레이어
- 팬레터 작성
- 요청 제출 후 성장 포인트 증가
- 더미 Growth Log

### Sprint 2

- 공식 에피소드 리더
- Canon Board
- 팬 요청 상태 변경
- 작가 스튜디오 기본 대시보드

### Sprint 3

- Character Bible
- Vlog Planner
- Fan Inbox
- 유료 unlock 연결

Sprint 1의 데모 목표:

> 팬이 브이로그를 보고 다음 장면을 요청하면, 캐릭터의 친밀도가 오르고 Growth Log에 기록된다.
