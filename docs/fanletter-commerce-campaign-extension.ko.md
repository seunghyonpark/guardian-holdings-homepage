# FanLetter 상품 성장 캠페인 확장 기획

## 1. 첫 적용 지점

FanLetter에 가장 먼저 붙일 기능은 팬 화면의 광고 노출이 아니라, 광고주와 운영자가 쓰는 `상품 URL 기반 캠페인 생성`이다.

핵심 문장:

> 광고주가 상품 URL을 넣으면, FanLetter가 상품에 맞는 AI 캐릭터 성장 캠페인을 만들고 공유링크로 성과를 추적한다.

이 기능은 기존 FanLetter Originals의 핵심 루프를 유지하면서 `캐릭터 성장 이벤트`의 새로운 원천을 추가한다.

```text
상품 URL 입력
  -> 상품 분석
  -> 캐릭터 적합도 추천
  -> 상품 경험 에피소드/브리프 생성
  -> 작가 또는 운영자 승인
  -> 캠페인 공유링크 발급
  -> 클릭/공유/구매/라방 유입 추적
  -> 캐릭터 성장 로그 반영
```

## 2. 포지셔닝

이 모델은 기존 캐릭터에 광고를 붙이는 방식이 아니다. 처음부터 캐릭터가 상품 경험을 통해 성장하는 구조다.

나쁜 표현:

> 캐릭터가 광고를 대신해준다.

좋은 표현:

> 상품 경험이 캐릭터의 성장 퀘스트가 된다.

FanLetter의 차별점은 광고주 상품을 캐릭터의 세계관, 취향, 성장 로그와 연결하는 것이다.

## 3. 1차 MVP 범위

1차 MVP는 완전 자동 광고 집행이 아니라 `캠페인 생성 + 승인 + 공유링크 + 성과 추적`까지만 다룬다.

포함:

- 광고주 상품 URL 입력
- 상품명, 대표 이미지, 가격, 설명, 카테고리 초안 추출
- 캐릭터별 상품 적합도 점수
- 캠페인 목표 선택: 클릭, 구매, 쿠폰, 라방 유입, 회원가입
- AI 캐릭터 소개 문구 생성
- 공유링크 생성
- 클릭/공유/전환 이벤트 기록
- Growth Log에 캠페인 기반 성장 이벤트 표시

제외:

- 광고비 자동 과금
- 외부 매체 자동 집행
- 완전 자동 콘텐츠 공개
- 구매 전환 보장
- 법적 심의가 필요한 상품군의 자동 승인

## 4. 사용자별 가치

### 광고주

광고주는 복잡한 광고 세팅 없이 상품 URL만으로 캐릭터 기반 캠페인을 만들 수 있다.

광고주가 얻는 결과물:

- 상품 카드
- 캐릭터 추천
- 캠페인 공유링크
- 공유용 카피
- 클릭/공유/전환 리포트

### 캐릭터 IP 홀더

IP 홀더는 초기 인지도가 낮아도 상품 캠페인을 통해 캐릭터 노출과 성장 데이터를 얻는다.

IP 홀더가 얻는 결과물:

- 캐릭터의 상품 경험 콘텐츠
- Growth Log 이벤트
- 상품군별 반응 데이터
- 향후 유료 광고 단가 산정 근거

### FanLetter

FanLetter는 광고주 상품, 캐릭터, 팬 행동 데이터를 함께 축적한다.

FanLetter가 얻는 자산:

- 상품 카테고리별 캐릭터 적합도 데이터
- 캐릭터별 클릭률/전환율
- 광고주 재집행 데이터
- 유료 캠페인 전환 기준

## 5. 캠페인 타입

| 타입 | 설명 | 예시 |
| --- | --- | --- |
| Product Quest | 캐릭터가 상품을 경험하며 성장하는 캠페인 | 자취 캐릭터가 소형가전으로 방을 업그레이드 |
| Review Vlog | 캐릭터가 상품을 소개하거나 비교하는 캠페인 | IT 캐릭터가 충전기 3종 비교 |
| Coupon Drop | 공유링크를 통해 쿠폰을 받는 캠페인 | 팬 전용 10% 할인 링크 |
| Live Commerce Boost | 라방 시청 유입을 만드는 캠페인 | 네이버 쇼핑라이브 사전 알림 유도 |
| Fan Mission | 팬이 공유/클릭/구매로 캐릭터 성장에 기여 | 500클릭 달성 시 새 의상 공개 |

## 6. 상품 URL 분석 항목

MVP에서는 자동 추출 후 광고주가 직접 수정할 수 있게 한다.

필수 항목:

- 상품명
- 상품 URL
- 대표 이미지
- 가격
- 브랜드명
- 카테고리
- 핵심 혜택
- 구매 링크 또는 랜딩 링크

AI 추정 항목:

- 타깃 고객
- 구매 동기
- 시연 가능성
- 팬덤 공유 적합성
- 캐릭터 적합 카테고리
- 금지/주의 표현

## 7. 캐릭터 적합도 기준

캐릭터마다 상품을 받을 수 있는 범위를 제한해야 한다. 그래야 캐릭터가 광고판처럼 보이지 않고, 상품 경험으로 성장하는 구조가 유지된다.

점수 기준:

| 기준 | 설명 |
| --- | --- |
| 세계관 적합도 | 캐릭터의 직업, 취향, 생활 반경과 맞는가 |
| 카테고리 적합도 | 캐릭터가 자연스럽게 다룰 수 있는 상품군인가 |
| 팬 관심도 | 기존 팬 반응과 맞는가 |
| 성장 기여도 | 상품 경험이 캐릭터의 성장 로그에 반영될 수 있는가 |
| 브랜드 안전성 | 허위/과장, 선정성, 민감 업종 리스크가 낮은가 |

추천 결과 예시:

```text
상품: 미니 공기청정기
추천 캐릭터: 하린, 자취 생활 캐릭터
적합도: 86점

추천 이유:
- 자취방 개선이라는 성장 퀘스트와 자연스럽게 연결됨
- 팬들이 방 꾸미기 요청을 반복적으로 보냄
- 제품 시연 장면을 30초 브이로그로 만들기 쉬움
```

## 8. 첫 화면 명세

경로 예시:

- `/advertiser/campaigns/new`
- `/studio/campaigns/new`

초기에는 광고주 공개 셀프서브보다 운영자/작가가 대신 생성하는 `관리형 캠페인 생성`으로 시작한다.

입력:

- 상품 URL
- 캠페인 목표
- 희망 캐릭터 또는 자동 추천
- 예산 없음/무료 테스트/성과형 중 선택
- 필수 문구
- 금지 문구
- 쿠폰 또는 혜택

출력:

- 상품 카드
- 추천 캐릭터 3개
- 캐릭터별 캠페인 브리프
- 공유링크 초안
- 공개 전 체크리스트

## 9. 승인 정책

캠페인은 자동 공개하지 않는다.

승인 흐름:

```text
광고주 캠페인 생성
  -> 상품 정보 검수
  -> 캐릭터 IP 홀더 승인
  -> 운영자 광고/안전 검수
  -> 공유링크 활성화
```

필수 표시:

- `광고`
- `AI 캐릭터 콘텐츠`
- 광고주명 또는 브랜드명
- 혜택/쿠폰 조건

민감 상품군:

- 건강기능식품
- 의료/미용시술
- 금융/투자
- 다이어트
- 미성년자 대상 상품
- 주류/성인 상품

이 상품군은 MVP에서 차단하거나 운영자 수동 승인 대상으로 둔다.

## 10. Growth Log 반영 방식

상품 캠페인은 캐릭터 성장 이벤트가 되어야 한다.

예시:

```text
하린의 생활력 +20
"팬들이 공유한 미니 공기청정기 캠페인으로 하린의 방이 업그레이드되었습니다."
```

성장 스탯 매핑:

| 행동 | 스탯 | 포인트 |
| --- | --- | --- |
| 캠페인 공유링크 클릭 | awareness | +1 |
| 캠페인 공유 | awareness | +5 |
| 쿠폰 다운로드 | revenue_power | +5 |
| 구매 전환 | revenue_power | +15 |
| 캠페인 목표 달성 | activity | +30 |
| 상품 경험 브이로그 공개 | story_power | +20 |

## 11. 수익화 단계

초기에는 캐릭터 IP 성장을 위해 무료 또는 저가 캠페인을 허용한다. 단, 무료 캠페인은 슬롯과 품질 기준을 둔다.

```text
Stage 1: 무료 테스트 캠페인
Stage 2: 성과형 캠페인
Stage 3: 고정 광고비 캠페인
Stage 4: 카테고리 독점/앰배서더 계약
```

유료 전환 기준:

- 캐릭터 월 캠페인 클릭 수
- 공유율
- 구매 전환 또는 쿠폰 다운로드
- 광고주 재집행률
- 특정 상품군 성과

## 12. 첫 릴리즈 성공 기준

파일럿 기준:

- 광고주 상품 URL 30개 등록
- 캐릭터 5개 이상에 상품 캠페인 매칭
- 캠페인 공유링크 20개 이상 활성화
- 캠페인 클릭률 3% 이상
- 광고주 재집행 의사 30% 이상
- 캐릭터 Growth Log에 캠페인 이벤트가 자연스럽게 반영된 사례 5개 이상

가장 중요한 검증 질문:

> 팬은 상품 캠페인을 캐릭터 성장의 일부로 받아들이는가?

이 질문에 답하기 전까지 자동 광고 집행이나 대형 광고주 영업으로 확장하지 않는다.
